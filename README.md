# Student Burnout Prediction System

## Overview
A Machine Learning project that predicts student burnout risk using academic, lifestyle, and psychological factors.

## Features
- Burnout Risk Prediction
- CatBoost Classifier
- SHAP Explainability
- Streamlit Web Application
- Data Analysis and Visualization

## Technologies Used
- Python
- Pandas
- NumPy
- CatBoost
- SHAP
- Streamlit
- Matplotlib

├── README.md
